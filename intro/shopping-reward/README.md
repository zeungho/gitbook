# 쇼핑-리워드 광고란?

쇼핑 전용 리워드 광고는 네이버+ 스토어 판매자를 위해 특화된 보상형 광고 상품입니다.\
일반고객 대비 평균 2배 이상 높은 구매 성향을 가진 네이버페이 회원에게, 합리적인 비용으로 단시간 집중적인 방문과 필요한 액션을 유도할 수 있습니다.
