# N쇼핑 CPS

**"N쇼핑 CPS" 광고란?**

> ‘N쇼핑 CPS’는 ‘네이버 쇼핑’ 과 ‘네이버페이’가 공동 개발하여 네이버+스토어에서 구매 시 기본 적립 외 추가 적립이 되는 광고 상품입니다. 구매력 있는 네이버페이 사용자를 대상으로 스토어 구매를 이끌어낼 수 있습니다.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

| **구분**         | **내용**                                                                                     | **비고**                                                                                |
| -------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| **광고단가**       | <p>•구매금액의 20% (VAT별도)<br>*구매 시 금액 기준으로 과금, 유저 취소 발생 시 광고비 제외 처리하여 정산 반영</p>                | <p>ex) CPS 광고를 통해 1만원 구매 발생 시<br>구매금액의 20%인 2,000원 광고비 과금, 구매확정 이후 취소분 반영하여 최종 정산</p> |
| **\*(필수)입점비**  | •캠페인 별 100만원 (VAT별도)                                                                       | \*배너 클릭 시 1원 적립 지원                                                                    |
| **고객 적립금**     | <p>•구매 금액의 10% N페이 적립(구매 확정 시 시스템을 통해 자동 적립)<br>•고객적립금은 “N페이＂가 부담하며 적립 비율은 상시 변동될 수 있음</p> | \*소수점 이하 반올림하여 1원 단위로 적립                                                              |
| **적립기준**       | •구매 상품의 구매확정이 완료 된 시점에 적립                                                                  |                                                                                       |
| **최소/최대 집행기준** | <p>•최소 집행 기준 없음<br>•최대 광고비 조건 설정 필수</p>                                                    | 최대 광고비 내 한도 제한, 최대 광고비 소진 시 캠페인 자동 종료                                                 |
| **광고 기간**      | <p>•캠페인 당 1일에서 최대 4주(28일)까지 집행 가능<br>•4주 초과 집행 시 캠페인 재등록 필요 (캠페인 당 입점비 100만원 별도 과금)</p>    | <p>ex) CPS 광고 40일 집행 희망 시,<br>20+20 or 28+12 등으로 기간 분할 등록</p>                         |
| **노출**         | <p>•네이버페이 > 포인트탭 > CPS광고 미션 배너<br>•외부매체 (KB페이, 케이뱅크, 신한카드,  국민은행 등)</p>                    |                                                                                       |
| **타겟팅**        | •별도 타겟팅 적용 불가                                                                              |                                                                                       |
| **정산**         | <p>•광고비는 선불을 기준으로 함 (CPS광고비 + 입점비)<br>•선불금 중 미 달성 발생 시 환불 또는 재 집행  중 선택 가능</p>             | \*CPS는 대행 수수료 없음                                                                      |
| **리포트**        | •노출, 클릭, 참여건수, 구매 금액, 구매확정 금액, 최종 정산 광고비 등                                                 | 실적 확인 가능한 어드민 제공                                                                      |
| **광고주**        | •네이버플러스스토어 입점 광고주면 집행 가능하나, 도서정가제 대상 상품, 디지털 콘텐츠, e쿠폰 및 환금성 카테고리 상품은 집행 불가함                | \*광고주 제한 카테고리 : 도서정가제 대상 상품, 디지털콘텐츠, e쿠폰 및 골드바/순금액세서리 등의 환금성 카테고리 상품과 상품권은 추가 적립 불가   |
