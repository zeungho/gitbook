# 방문 유도형 CPC

**대행사(NBT) 연동 필수 여부 : Optional**

**작동 방식**

배너 클릭 시 광고주 랜딩 페이지 바로 이동하여 이에 대해 소액의 포인트를 즉시 보상 합니다.

**특장점**

단시간에 대규모 트래픽을 원하는 랜딩 페이지로 집중합니다. 데일리캡 설정으로 트래픽 분산

**주의사항**

없음

**활용 사례**

N사의 정례 할인 행사 진행 시 관심 촉발을 위해 집행, ROAS 2,000% 달성

* 상기 사례는 참고를 위한 사례일 뿐이며, 네이버파이낸셜 및 광고 상품이 해당 효과를 보장하지 않습니다.
