# 리워드 광고란?

리워드 광고는 캠페인 미션 달성 시 네이버페이 포인트를 지급하는 보상형광고 상품으로 3,500만명 이상의 네이버페이 회원을 대상으로 SNS구독, 회원가입, 제품구매 등 광고주가 희망하는 다양한 미션을 유도할 수 있습니다.

✅ 서버 연동을 통한 실시간 리워드 적립과 연동이 필요 없는 수동 적립 방식 모두 가능합니다.

| **리워드 광고 타입**                         | **특징**                                                                |
| ------------------------------------- | --------------------------------------------------------------------- |
| [**금융 CPA (증권/보험 외)**](cpa.md)        | 멤버십 가입, 카드 개설, 계좌 개설, 금융 상품 가입 등 완료 시 과금 타입                           |
| [**증권 계좌 개설 CPA**](cpa-1.md)          | 증권 계좌 개설 완료 시 과금 타입                                                   |
| [**보험 가입 CPA**](cpa-2.md)             | 보험 가입 완료 시 과금 타입                                                      |

| [**미션 달성형 CPA (SNS팔로우)**](cpa-sns.md) | Facebook 좋아요, Youtube 구독, Instagram 팔로우, 네이버카페 가입 및 블로그 이웃 완료 시 과금 타입 |
| [**구매형 CPS**](cps.md)                 | 구매 완료 시 과금 타입                                                         |
