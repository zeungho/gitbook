# 머니브리핑 빅배너

### 텍스트 가이드

* 타이틀 8자 이내
* 서브타이틀 (내용) 37자 이내 (줄당 19자)
* 버튼 16자 이내
* 모두 공백 포함
* 텍스트 정의 영역 초과 시 말줄임 처리. 모든 해상도에 동일 적용&#x20;

### 이미지 가이드

* 일반형 의 썸네일 아 이 콘을 최대한 활용
* 별도 제작시 30x30 의 원 안에 20x20 의 그래픽을 넣어 제작 후 적용
* 일반형 아이콘의 그래픽 스타일과 유사하게 제작 권장
* 일반형 아이콘의 컬러, bg컬러 중 선택하여 제작 권장
* 특정 BI·CI 활용 필요 시 그대로 사용 가능, bg컬러는 일반형 아이콘 컬러 중 선택하여 제작 권장
* 이미지는 3x인 90x90, png로 출력해 사용
