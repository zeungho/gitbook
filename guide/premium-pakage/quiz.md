# 포인트탭 - 퀴즈 미션

<figure><img src="../../.gitbook/assets/포인트탭 광고기획 (1).png" alt=""><figcaption></figcaption></figure>



**① 퀴즈**

* 문제 글자 수 : 한 줄 당 공백 포함 12글자, 최대 2줄(24글자) 가능
* 정답 글자 수 : 최대 6글자, 한글/영어/숫자만 가능
* 정답 조건 : "힌트보기"에서 광고주 프로모션 랜딩 삽입\
  → 해당 프로모션 페이지에서 확인 가능한 단어여야 함

**② 퀴즈미션 내 메인 이미지**

* 사이즈 : 900\*900
* 형식 : PNG 혹은 JPG
* 배경이 흰색이 아닌 형태의 이미지

**③ 퀴즈 엔드 페이지**

* 메인 타이틀 : 한 줄 당 공백 포함 12글자, 최대 2줄(24글자) 가능
* 서브 타이틀 : 공백 포함 최대 20글자
