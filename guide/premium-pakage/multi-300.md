#### 이미지

1. 배너 이미지: 720 x 300px (png) / 400kb 미만
2. 썸네일 이미지: 123 x 123px

#### 텍스트

1. 텍스트 (메인카피)
   * 띄어쓰기 포함 20자 이내
   * 크기: 35pt / 컬러: #1E1E23 / 자간: -1px
2. 텍스트 (서브카피)
   * 띄어쓰기 포함 25자 이내
   * 크기: 28pt / 컬러: #767678 / 자간: -1px

#### 클릭버튼

* 고정문구 적용: 클릭하고 N 00원 적립
