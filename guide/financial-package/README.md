# 금융패키지

소재 검수 관련 안내사항

* 통합검색/네이버페이 증권 지면은 광고 형상 및 노출 방식이 상이하여, 동일 소재라도 지면별 검수 결과가 다르게 적용될 수 있습니다.
* 지면별 UI 구성, 텍스트 노출 범위, 상품 정보 표현 방식 등에 따라 일부 문구 수정 또는 소재 보완 요청이 발생할 수 있습니다.
* 금융 광고 특성상 광고주 내부 심의 및 협회 심의 기간을 고려하여, <mark style="background-color:$warning;">영업일 기준 최소 10일 전</mark> 소재 전달을 권장 드립니다.
